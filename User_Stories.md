# Step 2 — User Stories

Now we translate those requirements into stories.

## Epic 1 — Authentication & Access

### US-001 — Employee Login

> **As an employee, I want to securely log into the system, so that I can access internal job opportunities and my applications.**

### US-002 — TA Login

> **As a TA, I want to securely access the TA functionality, so that I can manage internal job postings and applications.**

### US-003 — Role-Based Access

> **As the organization, I want users to access only functionality permitted by their role, so that recruitment information remains secure.**

---

# Epic 2 — Employee Job Discovery

### US-004 — Browse Jobs

> **As an employee, I want to see open internal job postings, so that I can discover opportunities within the company.**

### US-005 — Search Jobs

> **As an employee, I want to search job postings by title, so that I can quickly find relevant opportunities.**

### US-006 — Filter Jobs

> **As an employee, I want to filter job postings by department, designation, skills, and due date, so that I can narrow the opportunities to those relevant to me.**

### US-007 — Sort Jobs

> **As an employee, I want to sort job postings by deadline, so that I can prioritize opportunities that are closing soon.**

### US-008 — View Job Details

> **As an employee, I want to view complete job details, so that I can decide whether the opportunity is suitable for me.**

---

# Epic 3 — Application

### US-009 — Apply Directly

> **As an employee, I want to apply directly from the job details, so that I can submit an application without unnecessary navigation.**

### US-010 — Confirm Application

> **As an employee, I want to confirm my application before submission, so that I don't accidentally apply for a job.**

### US-011 — Prevent Duplicate Active Applications

> **As an employee, I want the system to prevent duplicate active applications for the same posting, so that my application history remains consistent.**

### US-012 — Withdraw Application

> **As an employee, I want to withdraw an eligible application, so that I can stop participating in an opportunity when I change my mind.**

### US-013 — Reapply

> **As an employee, I want to reapply after withdrawing an application, so that I can reconsider the opportunity.**

---

# Epic 4 — My Applications

### US-014 — View My Applications

> **As an employee, I want to view my applications and their statuses, so that I can track my internal opportunities.**

### US-015 — Identify Application

> **As an employee, I want to see the associated job details, applied date, and deadline, so that I can understand which opportunity each application belongs to.**

---

# Epic 5 — TA Job Management

### US-016 — Create Posting

> **As a TA, I want to create a job posting, so that employees can discover an internal opportunity.**

### US-017 — Create From Template

> **As a TA, I want to create a posting from a job template, so that I don't have to repeatedly enter common job information.**

### US-018 — Modify Template Data

> **As a TA, I want to modify template-populated information before publishing a posting, so that the posting accurately reflects the current opening.**

### US-019 — Manage Postings

> **As a TA, I want to retrieve, update, and delete eligible job postings, so that I can maintain accurate recruitment information.**

---

# Epic 6 — Posting Lifecycle

### US-020 — Open Posting

> **As a TA, I want to open a job posting with a deadline, so that employees can apply during a defined period.**

### US-021 — Close Posting

> **As a TA, I want to manually close a posting, so that I can stop accepting applications when necessary.**

### US-022 — Automatic Closure

> **As a TA, I want postings to automatically close when their deadline passes, so that applications cannot be submitted after the recruitment period.**

### US-023 — Reopen Posting

> **As a TA, I want to reopen a closed posting with a new deadline, so that I can continue accepting applications when required.**

### US-024 — Complete Posting

> **As a TA, I want to mark a posting as completed after all applications have reached terminal states, so that I can distinguish finished recruitment processes from merely closed postings.**

---

# Epic 7 — TA Application Management

### US-025 — View Applications

> **As a TA, I want to view applications associated with a posting, so that I can review candidates.**

### US-026 — Update Application Status

> **As a TA, I want to update an application's status through valid workflow transitions, so that I can manage the recruitment process accurately.**

### US-027 — Reconsider Candidate

> **As a TA, I want to move a shortlisted candidate back to under review, so that I can reconsider the candidate after further discussion.**

---

# Epic 8 — Notifications

### US-028 — Employee Status Notification

> **As an employee, I want to receive notifications when my application is shortlisted, reaches interview, is selected, or is rejected, so that I know what is happening with my application.**

### US-029 — TA Deadline Reminder

> **As a TA, I want to configure a reminder before a posting deadline, so that I don't forget about an approaching closing date.**

### US-030 — TA Closure Notification

> **As a TA, I want to be notified when a posting automatically closes, so that I know the recruitment period has ended.**

---

# Epic 9 — Job Templates

### US-031 — Manage Templates

> **As a TA, I want to create, view, update, and delete job templates, so that I can reuse common job information.**

---

# Epic 10 — Employee Profile

### US-032 — Maintain Profile

> **As an employee, I want my internal profile to contain my professional information and skills, so that the system can use accurate information for applications and future compatibility checks.**

---

# Epic 11 — Compatibility — Phase 3

### US-033 — Compatibility Score

> **As a TA, I want to see a compatibility percentage between an employee and a job's requirements, so that I can quickly understand how closely the candidate matches the role.**

### US-034 — Recommended Jobs

> **As an employee, I want to see jobs that closely match my experience and skills, so that I can discover relevant internal opportunities.**

---
